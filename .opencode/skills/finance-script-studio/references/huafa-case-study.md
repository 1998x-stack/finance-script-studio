# 示例：珠海华发集团流动性事件（核查截至2026-11-09）

## 核心问题

一家合并总资产7229.64亿元、维持AAA主体评级的地方国企，为何仍被评级机构列入负面观察？

## 经核对的最小事实集

- 2026-11-04 联合资信公告：维持主体及相关债券AAA，并列入负面观察；2026-09末资产7229.64亿元、前三季度利润总额-77.24亿元、经营净现金流-15亿元；存货及投资性房地产占资产比重>45%。**原始评级公告**：https://static.cninfo.com.cn/finalpage/2026-11-04/1225658466.PDF
- 2026-06末集团货币资金574.22亿元，来自2026半年度债券报告合并报表；同口径一年内到期债务1541.04亿元、有息债务4047.26亿元，见半年报与2026-11-08《每日经济新闻》核对。**半年报**：https://static.cninfo.com.cn/finalpage/2026-08-31/1225538620.PDF
- 已落地支持资金超400亿元、后续计划统筹近700亿元，为2026-11-04采访所述，不是财政直接一次性拨款1100亿元。**采访转述**：https://finance.caixin.com/2026-11-04/102501030.html
- 联合资信公告列示“23华发集团MTN006”10亿元于2026-11-17到期；截至本示例截止日期，**不能推断之后的实际兑付结果**。

## 口播主线

反常识：资产高、评级AAA却出现流动性压力。
证据：1541.04短期到期与574.22货币资金（均6月末）。
机制：资产变现慢、现金回流弱、融资续接存在不确定性。
修正：珠海披露支持，但不同资金状态不可混淆。
回报：资产规模不等于偿债现金，评级不保证零风险。

## 必须保留的限定

不能把“现金少于短期债务”直接算成确定的现金缺口；不能把全年短债余额看成同一天到期；不能把华发集团与华发股份财报混用；不能把信托媒体争议写成已确认的公开债实质违约。
