# 180秒财经口播：叙事、钩子与语言

## 核心模型

反常识开场 → 事件边界 → 数字冲击 → 机制解释 → 有证据的修正 → 认知回报。

| 时间 | 观众要获得什么 | 内容 |
|---|---|---|
| 0—15s | 为什么听 | 一句真实反差 + 问题 |
| 15—45s | 发生什么 | 主体、官方动作、尚未发生的事 |
| 45—105s | 为什么如此 | 同口径数字、因果链、生活类比 |
| 105—150s | 还有什么复杂性 | 外部支持、反方证据、限制条件 |
| 150—180s | 能记住什么 | 清晰答案和可迁移的规则 |

时间可因题材伸缩。连续两句不能只表达相同观点。每个段落必须推动一个新理解；凡删掉后逻辑不变的句子可考虑删掉。

## 三类开头优先选一种

- 数字反差：“有XX资产，为什么只有YY能马上用？”
- 预期落差：“通常我们以为A，但这次B出现了。”
- 机制问题：“政策明明想解决X，为什么企业实际遇到Y？”

开头不是独立的钩子工程：正文必须回答这个问题。禁止虚构“内部消息”“极度震惊”等引导。

## 数字口播转换

选3个关键数字，先给读者熟悉的量级，再让两个同口径数字比较。数字密集时用屏幕卡片，不在一个句子里连续念6个金额。四舍五入不应改变计算或真实含义。把“货币资金”称为“账面货币资金”，而非未经核实的“可用现金”。

## 类比策略

类比是帮助观众理解机制的脚手架，而非企业会计事实。典型结构：“就好比……；当然，这只是类比，企业还存在……”。可以使用房产与还款、家庭现金与负债、工厂库存与订单，但不能给观众造成真实兑付缺口已算出的错觉。

## 口播语言校对

读稿时检查：句长、转折、金融术语密度、数字停顿。默认180秒约600—750汉字，只是起点；用实际音频朗读调整语速。重点数字说慢，结论前保留半秒停顿。句子宜自然、短、连贯，不要全篇都是“我认为”。

## 结尾

回答开头问题，告诉观众如何用同一框架看其他企业。结尾可设置一个可验证的观察指标（如未来债券兑付），但不要把未知结果暗示成确定结局。不要为引导评论编造二元对立。
