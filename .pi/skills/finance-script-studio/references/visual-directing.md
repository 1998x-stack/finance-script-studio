# 视觉导演：专业严肃的财经口播

## 设计系统

默认平台为9:16竖屏短视频；网页为响应式专业财经杂志。建议配色：深海军蓝 #0e1c2d、近白纸张 #f5f4f0、沉稳金 #c0a273、数据绿 #448b88。使用系统中文字体，不上传未经授权的字库。用留白、网格、精确数据来源建立可信度，而非“金融危机红屏”。

## 画面角色

- **真人镜头**：建立关系、解释观点、在疑问/结论处停留。
- **公告截图**：展示机构、日期、关键语句，不裁剪出改变原义的内容。
- **数字卡**：两至三个金额，一次看懂；数据写统计日、单位与口径。
- **条形图**：同一单位和时点的大小比较；禁从不为零的轴起点制造幅度。
- **因果图**：最多3—5个节点和箭头，解释机制而非装饰。
- **类比画面**：明确“示意/类比”，避免被误认为当事企业项目图。

## 字幕与音频

普通字幕用于无声观看；每一屏只突出一个关键词或数字。严肃口吻、中速语气、关键数字前停顿。音量不要靠惊悚配乐替代论证。屏幕小于400px时数字和来源应仍可读；不要把完整PDF缩成难以辨认的页面。

## 场景节奏

镜头切换以信息变化驱动，不固定3秒剪辑。约每20—30秒给出一次新的事实或解释；一个新信息点可由主播→数据→主播完成视觉闭环。减少炫技缩放、持续跳跃字幕和密集粒子特效。

## 网页组件

首页：栏目矩阵、首篇焦点及研究索引。文章页：日期与时点、关键数字、核心结论、解释正文、180秒口播脚本、参考来源和fact-check。移动端必须单列布局，来源可点击，正文对比度可读。
