# 研究与证据核查协议

## 来源优先级

一级：企业/交易所/中国货币网/清算所/审计报告/评级原始公告/政府公开文件；二级：明确署名、引用来源的专业财经媒体及记者调查；三级：转述与二次聚合，仅作线索。对无法访问原文、付费墙或存在争议的事实，要标明核查限制。

## 每条重要事实记录

- **claim**：将要在口播说出的准确句子；
- **subject**：集团、上市子公司、项目公司、地方政府等；
- **period**：数据时点或统计期间；不要混合；
- **value**：数值、币种、单位、四舍五入情况；
- **source**：原始文件 URL、机构、发表日期、页码或具体章节；
- **classification**：verified / attributed / analysis / scenario；
- **checked_at**：本次核查日期；
- **caveat**：边界条件、未核实的细节、可能改变结论的因素。

## 必须对口径敏感

1. **资产 vs 现金**：土地和房产不是随时可以使用的货币；合并货币资金含可能受限资金。
2. **存量 vs 流量**：季度经营净现金流不能直接和时点总债务简单相减得到资金缺口。
3. **集团 vs 母公司**：受限资产、合资公司权益和跨主体资金调拨需要穿透。
4. **到期 vs 回售**：不能把某一债券的到期日当成全部债务偿还时间。
5. **支持政策 vs 现金到账**：已批准、已签约、已落地、已收款和可以用于还债不是同义词。
6. **评级 vs 履约**：负面观察、评级下调、实质违约是不同事实。
7. **媒体报道 vs 官方确认**：信托、调查、展期谈判等争议事项明确归属和日期。
8. **分析 vs 预测**：使用“如果……可能……”并说明触发条件，不能伪造概率。

## 发布时的证据规则

每个 key_numbers 都须至少一个 source_id；正文中有可核实的具体数据/重大行为要加 source_ids；分析段可不强绑引用，但必须写成“分析认为/可能/不能单凭…判断”。所有 sources 为 https 链接，能从页面直接点击。

发现来源冲突时先停止发布相应断言，并列出冲突的时点、口径或统计定义。无证据时允许删去论点，不能自己补数。

## 更新与纠错

重大事件增加新债务兑付、处罚、审计或资产交易完成信息时，创建新的核查记录，更新 updated_at 和对应段落。不要直接覆盖旧研究截止日而不调整证据；历史文章应保留 as_of。
