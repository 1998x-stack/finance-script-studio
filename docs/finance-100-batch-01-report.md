## 真实信息与示意信息的区别

1. **基础教育原理**：主要参考 OpenStax 的经济学教材及英格兰银行、巴塞尔委员会等概念说明。教材原理和不同经济体的制度安排不能随意混用；每期 `research.md` 保留来源。
2. **中国统计与制度**：GDP/CPI/PPI/调查失业率参考国家统计局公开定义，涉及 M1 则明确从2025年1月起实施的新统计口径，不能直接把新旧M1变动当经济转折。
3. **明确截止日的数据**：EP021 与 EP024 采用中国人民银行截至2026年9月末（或2026年前三季度）公开数据，不能不更新日期就改为“最新数据”，并须区分余额存量与期间增量。
4. **教学案例不是真实财经新闻**：所有奶茶店、二手车、草莓价格、假设的银行资产负债表等数字是为解释机制设计的情景，正式出片须标注“假设”。
5. **仍需独立核查**：内容是编辑初稿而非权威审计或已批准报道。源链接可供复核，不代表所有逐字论点已人工逐句对照原文；真实数据需再查公开原表与发布日期，测算须重算。

## 如何逐期开始审稿

1. 先阅读 `script.md`，检查标题与唯一问题是否吻合，术语表达有没有误导。
2. 对照 `research.md` 中来源ID，逐项验证现实日期、机构、数字和事实—推论边界，必要时新增原始公告页。
3. 复算情景算术；例如 EP009 比较优势、EP011 增加值、EP017 GDP 支出法、EP026 费雪关系、EP029 静态现金差额。
4. 真实录音检验各段时间，每期目前约500—620个中文字符（含标点），不承诺每一篇自然语速恰好180秒。根据试录结果调整段落和镜头。
5. 校对 9:16 字幕、图表日期与来源，以及所用素材的版权和平台合规提示。
6. 完成双人或独立终审后才把期号状态改为 `approved`，并单独批准将相应的 article JSON 改为 `published`。
