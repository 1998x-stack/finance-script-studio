## 具体方法

本批依据 `skill-src/finance-script-studio/SKILL.md` 及 `references/research-and-fact-check.md`、`narrative-architecture.md`、`visual-directing.md`、`compliance-and-review.md` 制作。

1. **唯一问题**：每期围绕原 `brief.md` 的传播问题组织“矛盾→定义→机制与算例→修正→可迁移观察点”。
2. **来源层级**：央行、财政部、财政会计准则、IFRS准则、IMF、CFA Institute以及开放教材按不同权重使用；`research.md` 为每期逐条登记网址、资料时点、用途和不适用范围。
3. **现实与假设分离**：仅在有原始公告时保留真实制度与数据，其他所有商业经营数字、负债和利润例子都标注为“假设”。
4. **规范口径**：财政赤字流量≠政府债务存量；政府法定债务≠融资平台企业债。LPR是报价参考，贷款合同重定价另有规则。会计分析需要区分合并报表与母公司、时点与期间、利润和现金。
5. **有用画面**：每期五行9:16分镜并配具体图卡、字幕重点，需标注数字单位、资料日期和模拟案例属性。
6. **审核优先**：事实、算术、来源有效性、最新监管/平台规则为硬性门槛；没有达到不通过发布。

## 特别提醒

- **EP033**：LPR的2026-10-20报价为**当日报价**，不是永久有效利率；2024–2025年的政策利率框架改革要区分当年与早期机制。
- **EP036/038**：财政债务涉及不同预算体系与法律主体。企业相关债务不得直接混为法定政府债务。
- **EP037**：财政乘数的100→60→36是教学支出传递链，不能当作实际GDP增幅或有统计证据的乘数。
- **EP044/046/048/050**：经营杠杆、现金转换周期、定价贡献、ROIC例子皆为简化静态计算，真实报表还需要考虑税费、期间、平均余额和资本成本。
- **EP053/055**：现金流表的经营、投资和筹资分类依据企业适用准则；自由现金流不是法定单一会计科目，各计算版本需明确。
- **EP056/058/059**：应收减值、商誉测试与偿债现金覆盖要求严格会计和合同复核，不能以静态现金差额断言“必然违约”。
- **资料日期**：个别权威网页没有标注精确发布时间，`article.sources[].published_at` 受既有schema限制用查阅日或课程年份占位，`type` 和 `research.md` 已明示；不可误写为实际发布日期。
