# 财经核心100概念：180秒口播课程地图

> 状态：**选题与体系设计完成**；本文件是百期课程的内容地图，**不是100篇已完成、已核查的口播稿**。
> 版本：2026-11-09 · 核心目标：每期只讲透**一个概念、一条机制、一个现实应用**，先解释，再判断，不提供个性化投资建议。

## 为什么按这个顺序

以“个人经济决策 → 宏观环境 → 货币财政 → 公司报表 → 融资与债务 → 资产估值 → 市场交易 → 风险配置 → 家庭应用”的知识依赖组织，而不是按热点或金融行话堆叠。每个概念的右栏就是独立三分钟视频的**唯一主问题**；切勿把它扩展为多个概念拼盘。

## 每期180秒制作规格

- **00–15秒：** 一个日常反差/真实问题，不虚构事件或人物。
- **15–45秒：** 用一句准确、通俗的定义说明概念，并交代适用边界。
- **45–110秒：** 一个可计算的简例或有来源的公开案例，解释机制与因果。
- **110–150秒：** 一个常见误解或反例，说明“什么时候不成立”。
- **150–180秒：** 用一句可迁移的判断准则收束，并给出下期知识连接。

建议每期初稿约600–750汉字，再按主播实际语速与数据停顿校准。正式出片需要独立完成来源核查、事实/观点区分和画面分镜，依据 `skill-src/finance-script-studio/SKILL.md` 与 `references/` 的相关规范执行。

## 发布顺序与质量门槛

1. **基础认知（001–040）**：确保观众不会把价格、货币、通胀、财政债务混为一谈。
2. **企业与投资（041–080）**：以报表、现金流、杠杆、估值和交易机制为主，尽可能使用真实公开文件做示范。
3. **风险与生活（081–100）**：解释“收益、波动、期限、家庭流动性”之间的取舍，不输出个股建议。

每一期正式产出必须包含：选题目标、核心定义、可追溯来源、一个清晰例子、必须澄清的误解、600–750字口播初稿、180秒分镜、标题/封面、事实核查清单与结构化 article JSON（如需发布网页）。

发布状态用 `content/articles/<slug>.json` 的 `draft/published` 管理；本选题地图不应被网站当成已经发表的100篇文章。优先打样：机会成本（002）、通货膨胀（014）、流动性与偿付能力（029）、现金流量表（043）、信用评级与展望（058）、复利（062）、ETF（075）、资产配置与再平衡（089）、应急储备金（092）。
